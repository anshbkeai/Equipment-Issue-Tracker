📘 Quick Guide

This is an Issue Tracker System designed to manage engineering parts, documents, and issues in one place.

📦 Parts Module

Manage all engineering parts with name, description, and metadata.

📄 Documents Module

Attach URLs and documentation files to each WT Part for reference.

🐞 Issue Tracker

Log and track system or product issues linked to specific parts.

🔁 System Flow
  1. Create a Part
  2. Attach Documents to Part
  3. Report Issues for Parts
  4. Track everything from Dashboard
